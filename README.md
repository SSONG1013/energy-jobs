# 방사선 · 원자력 · 비파괴검사 · 에너지 채용공고 공유 사이트

**전국 공공기관 + 민간기업** 채용공고 중 **방사선 · 원자력 · 비파괴검사 · 에너지** 관련 공고만 골라
매일 아침 자동으로 갱신해 보여주는 공유 웹사이트입니다. PC를 꺼 두어도 GitHub가 대신 실행합니다.

| 화면 항목 | 내용 |
|---|---|
| 채용기관명 | 공고를 낸 기관·기업 |
| 채용 직무 분야 | 공공기관: NCS 직무분야 / 민간기업: 사람인 직무 (예: 비파괴검사, 기계설계) |
| 서류제출 마감일 | 접수 마감일 + D-day (3일 이내는 주황색 강조). 민간기업의 '채용시·상시' 공고는 그대로 표시 |
| 공고 제목 | 누르면 원문 공고로 이동 |

그 밖에: 분야 탭(전체/방사선/원자력/비파괴검사/에너지), 공공·민간 선택, 근무지역 선택(전국 기본), 검색, 정렬,
**오늘 조회수 · 누적 조회수**, AI 안내 문구.

## 수집 출처
| 구분 | 출처 | 필요한 키 (GitHub Secret 이름) |
|---|---|---|
| 공공기관 | 잡알리오 (공공데이터포털 「재정경제부_공공기관 채용정보 조회서비스」) | `ALIO_API_KEY` |
| 민간기업 | 사람인 채용공고 API | `SARAMIN_ACCESS_KEY` |

- 두 키 중 **하나만 있어도** 동작합니다. 사람인 키를 아직 못 받았다면 공공기관 공고만 먼저 나오고, 키를 등록한 날부터 민간기업 공고가 추가됩니다.
- 한쪽 출처가 실패하면 그쪽은 **전날 자료를 유지**하고, 다른 쪽은 정상 갱신됩니다. (GitHub가 실패 알림 메일을 보내줍니다)
- 참고: 고용24(구 워크넷) 채용정보 API는 **기업회원 전용**이라 개인은 신청할 수 없어 사용하지 않았습니다.

## 처음 한 번만 하는 설정 (약 20분)

### 1-A. 공공기관 키 — 공공데이터포털
1. https://www.data.go.kr 로그인
2. **「재정경제부_공공기관 채용정보 조회서비스」** 검색 (https://www.data.go.kr/data/15125273/openapi.do) → **활용신청**
   - 개발계정은 자동 승인 (하루 1,000회 — 이 사이트는 하루 10~20회 사용)
   - ⚠ 다른 API를 이미 신청했더라도 **이 API는 따로 활용신청**해야 합니다.
3. 마이페이지 → 활용신청 현황 → **일반 인증키(Decoding)** 복사 (승인 후 활성화까지 1~2시간 걸릴 수 있음)

### 1-B. 민간기업 키 — 사람인
1. https://oapi.saramin.co.kr 접속 → 사람인 계정으로 로그인 → **이용신청**
2. 사용 목적 예시: "방사선·원자력·비파괴검사·에너지 분야 채용공고를 모아 보여주는 비영리 개인 정보 공유 사이트"
   - 사이트 주소 칸에는 4단계에서 생기는 `https://<GitHub아이디>.github.io/energy-jobs/` 를 적으면 됩니다.
3. 승인되면 발급되는 **access-key** 복사
   - 사람인 측 심사가 있어 승인까지 며칠 걸리거나 반려될 수 있습니다. 그동안은 공공기관 공고만 표시됩니다.

### 2. GitHub 저장소 만들기
1. GitHub 로그인 → 오른쪽 위 **+ → New repository**
2. 이름 예: `energy-jobs` / **Public** 선택 (무료 GitHub Pages는 공개 저장소에서 동작) → Create
3. **Add file → Upload files** 로 이 폴더 안의 내용 전체를 끌어다 놓고 Commit
   - `.github` 폴더는 숨김 폴더라 빠지는 경우가 있습니다. 올라갔는지 꼭 확인하세요.
     안 보이면 **Add file → Create new file** → 파일 이름 칸에 `.github/workflows/update-jobs.yml` 입력 후 내용을 붙여넣으세요.

> 저장소에는 이 폴더의 파일만 올라갑니다. OneDrive의 다른 자료는 공개되지 않습니다.

### 3. 키를 비밀값으로 등록
저장소 **Settings → Secrets and variables → Actions → New repository secret** 에서 두 개 등록
- `ALIO_API_KEY` = 1-A의 인증키
- `SARAMIN_ACCESS_KEY` = 1-B의 access-key (승인 전이면 나중에 추가)

(비밀값은 사이트나 코드에 노출되지 않습니다.)

### 4. 사이트 공개 (GitHub Pages)
**Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / 폴더: **/docs** → Save
→ 1~2분 뒤 `https://<GitHub아이디>.github.io/energy-jobs/` 로 열립니다. 이 주소를 공유하면 됩니다.

### 5. 첫 업데이트 바로 실행
**Actions** 탭 → (처음이면 enable 클릭) → **채용공고 자동 업데이트** → **Run workflow**
→ 초록색 체크가 뜨면 사이트를 새로고침해 공고가 보이는지 확인합니다.

이후에는 **매일 아침 8시 전후**에 자동으로 갱신됩니다.

## 알아두면 좋은 점
- **갱신 시각**: GitHub 예약 실행은 10~30분 늦게 시작되는 일이 잦아 한국시간 07:40에 시작하도록 설정했습니다.
- **조회수**: 무료 카운터 서비스(counterapi.dev) 사용. 같은 브라우저는 하루 1번만 집계되어 "하루 몇 명이 봤는지"에 가깝게 셉니다. 외부 서비스라 가끔 `–`로 보일 수 있습니다.
- **분류 기준 바꾸기**: `scripts/fetch_jobs.py` 위쪽의 목록만 고치면 됩니다.
  - `KEYWORDS` : 제목·직무에 들어가면 분류되는 단어 (비파괴검사: 비파괴, NDT, 초음파탐상, 방사선투과, 자분·침투탐상, 와전류, 가동중검사(ISI), PAUT 등)
  - `AGENCY_KEYWORDS`, `AGENCY_EXACT` : 공공기관 이름 기준 분류
  - `SARAMIN_QUERIES` : 사람인에서 검색할 단어
- **민간기업 공고**: 사람인 검색은 공고 본문까지 찾기 때문에 관련성이 낮은 공고가 가끔 섞일 수 있습니다. 거슬리면 `SARAMIN_QUERIES` 단어를 줄이세요.
- **업데이트 실패 시**: Actions 탭의 실패 로그에서 원인을 볼 수 있습니다. `resultCode=30`(잡알리오)이나 `code=2`(사람인)는 키 문제입니다.
